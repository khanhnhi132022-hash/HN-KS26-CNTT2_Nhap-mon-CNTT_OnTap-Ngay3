# Website Trung tâm Tiếng Anh TTA

## Giới thiệu

Website TTA giúp học viên tìm hiểu khóa học và gửi đăng ký trực tuyến.

Dự án hỗ trợ **quản lý thông tin khóa học** và _tra cứu học phí._

## Cấu trúc thư mục

| Thư mục | Nội dung |

|---|---|

| `data` | Bảng học viên và học phí |

| `docs` | Tài liệu của dự án |

| `logs`| Nhật ký hoạt động |

| `media` | Hình ảnh và logo |

| `archive` | Tài nguyên lưu trữ |

## Quy trình đăng ký học

1. Chọn khóa học muốn đăng ký.

2. Điền thông tin và gửi biểu mẫu đăng ký.

3. Kiểm tra học phí và hoàn tất thanh toán.
